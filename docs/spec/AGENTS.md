# Instructions for the from-scratch build agent

Read `00-build-contract.md` before reading any other file. This directory is
the complete context package for the original implementation experiment.

- Treat `01-product-requirements.md`, `02-domain-and-workflows.md`,
  `03-security-and-privacy.md`, and `05-acceptance-matrix.md` as mandatory.
- Treat `04-architecture-options.md` and `06-implementation-plan.md` as
  recommendations that may be changed with a recorded decision.
- Read `07-independent-build-boundary.md` before using any external asset or
  requirement source.
- Build in a new empty repository or isolated worktree.
- Do not inspect or use the working demo source, tests, migrations, screenshots,
  styles, markup, copy, or Git history.
- Ask before inventing business rules or resolving ownership questions.
- Report evidence, failures, open risks, and tests that were not run.
